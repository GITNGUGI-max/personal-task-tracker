# Personal Task Tracker

A React application for managing daily tasks.

## Features

- Add tasks.
- Edit Task
- Mark tasks complete or active.
- Delete tasks.
- Save tasks in the browser using localStorage.
- Responsive layout for desktop and mobile.

## Technologies

React, JavaScript, CSS, and Vite.

## Run locally

1. Run `npm install`.
2. Run `npm run dev`.
3. Open the local URL printed in the terminal.

## Production build

Run `npm run build` to generate the deployable files in `dist`.

Run `npm run preview` to preview the production build locally.

## Storage

Each visitor's tasks are stored locally in their browser.
